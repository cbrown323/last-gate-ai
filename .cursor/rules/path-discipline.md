# Path discipline — Last Gate AI

Last Gate AI is a **Next.js 15 App Router + TypeScript** app. Application code lives under **`app/`**, **`components/`**, **`lib/`**, **`types/`**, and **`prisma/`**.

## Before suggesting edits or `@`-mentions

1. **Verify the path exists** in the repo (search or list directories) before naming it in a plan or task capsule.
2. **Do not assume** a Vite `src/` tree, Laravel `resources/`, or Bootstrap jQuery patterns unless those paths actually exist here.
3. **Prefer** `app/api/` for server routes, `lib/` for shared server/client utilities, `components/ui/` for shadcn primitives.
4. If a **new** file is required, name it with a clear **`NEW:`** prefix in the plan and place it under the planned structure in `workflow_guide/AI_PROJECT_STATE.md`.

Workflow and agent rules live in **`workflow_guide/`** and root **`AGENTS.md`** — keep documentation paths consistent (`workflow_guide/AI_PROJECT_STATE.md`, `workflow_guide/DEV_LOG.md`).
